# Pulse App - Quick Reference Guide

## Before Deployment

### Pre-flight Checklist
```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Set environment variables
export DEBUG=False
export SECRET_KEY='generate-new-key'
export DATABASE_URL='postgresql://...'

# 3. Collect static files locally
python manage.py collectstatic --noinput

# 4. Run migrations
python manage.py migrate

# 5. Test locally
python manage.py runserver

# 6. Verify static files loaded in browser
# Open http://localhost:8000
# Check: CSS loads, theme toggle works, images show
```

## Environment Variables

### Required for Production
```
DEBUG=False
SECRET_KEY=<generate-new-key>
ALLOWED_HOSTS=yourdomain.com,yourdomain.vercel.app
DATABASE_URL=postgresql://user:pass@host:port/db
CORS_ALLOWED_ORIGINS=https://yourdomain.com,https://yourdomain.vercel.app
CSRF_TRUSTED_ORIGINS=https://yourdomain.com,https://yourdomain.vercel.app
```

### Generate SECRET_KEY
```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

## Configuration Summary

### settings.py
```python
INSTALLED_APPS = [
    ...
    'whitenoise.runserver_nostatic',  # ← Add this
    'django.contrib.staticfiles',
    ...
]

MIDDLEWARE = [
    'django.middleware.security.SecurityMiddleware',
    'whitenoise.middleware.WhiteNoiseMiddleware',  # ← Add this
    ...
]

STATIC_URL = '/static/'
STATIC_ROOT = BASE_DIR / 'staticfiles'
STATICFILES_STORAGE = 'whitenoise.storage.CompressedManifestStaticFilesStorage'
```

### vercel.json
```json
{
  "buildCommand": "python manage.py collectstatic --noinput",
  "routes": [
    { "src": "/static/(.*)", "dest": "/staticfiles/$1" },
    { "src": "/(.*)", "dest": "socialmedia_backend/wsgi.py" }
  ]
}
```

### HTML Templates
```html
{% load static %}
<link rel="stylesheet" href="{% static 'styles.css' %}">
<script src="{% static 'app.js' %}"></script>
```

## Troubleshooting

### CSS Not Loading?
```
1. Check vercel.json routes configuration
2. Verify STATIC_ROOT in settings.py
3. Look for collectstatic errors in build logs
4. Clear Vercel cache → redeploy
```

### Static Files 404?
```
1. Ensure staticfiles/ directory exists
2. Check STATIC_URL = '/static/' in settings.py
3. Verify vercel.json routing for /static/
4. Check file names (WhiteNoise adds hash)
```

### Theme Toggle Not Working?
```
1. Check app.js loaded in Network tab
2. Open Console: document.documentElement.getAttribute('data-theme')
3. Check localStorage: localStorage.getItem('theme')
4. Verify styles.css includes [data-theme="dark"] styles
```

### Images Broken?
```
1. Use Gravatar for avatars (built-in fallback)
2. Verify media file paths
3. Check MEDIA_URL and MEDIA_ROOT
4. CSS provides gradient placeholder
```

### Mobile Layout Wrong?
```
1. Check styles.css @media (max-width: 768px)
2. Verify bottom-nav display: flex in media query
3. Check body padding-bottom: 56px
4. Clear cache and hard refresh (Ctrl+Shift+R)
```

## Debugging Tips

### Browser DevTools
```
1. Network Tab
   - Check static file requests
   - Look for 404s and 500s
   - Monitor response size and time

2. Console Tab
   - Check for JavaScript errors
   - Type: localStorage.getItem('token')
   - Type: document.documentElement.getAttribute('data-theme')

3. Application Tab
   - Check localStorage items
   - Verify 'theme' and 'token' stored
   - Clear Site Data if needed

4. Lighthouse
   - Run mobile audit
   - Check Performance score
   - Review accessibility issues
```

### Server Logs (Vercel)
```
1. Go to Vercel Dashboard
2. Select Project → Deployments
3. Click latest deployment
4. View "Build Logs" tab
5. Look for collectstatic output
6. Check for any errors during build
```
