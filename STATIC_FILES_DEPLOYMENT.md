# Pulse Social Media App - Vercel Static Files Deployment Guide

## Overview

This Django application is configured for serverless deployment on Vercel with proper static files serving using WhiteNoise.

## Key Configuration Changes Made

### 1. WhiteNoise Configuration (settings.py)

✅ Added `'whitenoise.runserver_nostatic'` to INSTALLED_APPS (before django.contrib.staticfiles)
✅ WhiteNoise middleware already configured in MIDDLEWARE
✅ Static files storage configured to use CompressedManifestStaticFilesStorage

```python
INSTALLED_APPS = [
    ...
    'whitenoise.runserver_nostatic',      # Handles static files in production
    'django.contrib.staticfiles',
    ...
]

MIDDLEWARE = [
    'django.middleware.security.SecurityMiddleware',
    'whitenoise.middleware.WhiteNoiseMiddleware',  # Serves static files
    ...
]

STATIC_URL = '/static/'
STATIC_ROOT = BASE_DIR / 'staticfiles'
STATICFILES_STORAGE = 'whitenoise.storage.CompressedManifestStaticFilesStorage'
```

### 2. Vercel Configuration (vercel.json)

Updated with:
- `buildCommand`: Runs `collectstatic` during build
- Proper `routes` configuration for `/static/` paths
- Cache headers for optimal performance
- Output directory configuration

```json
{
  "buildCommand": "python manage.py collectstatic --noinput",
  "builds": [...],
  "routes": [
    {
      "src": "/static/(.*)",
      "dest": "/staticfiles/$1",
      "headers": { "cache-control": "public, max-age=3600, immutable" }
    }
  ]
}
```

### 3. HTML Templates Updated

All HTML templates now use Django's `{% load static %}` and `{% static %}` template tags:

## Deployment Steps

### Step 1: Prerequisites

- Vercel account (https://vercel.com)
- GitHub repository with the code pushed
- PostgreSQL database (required for production)

### Step 2: Set Up Environment Variables in Vercel

Go to project settings → Environment Variables and add:

```
SECRET_KEY=your-secret-key-here
DEBUG=False
ALLOWED_HOSTS=your-domain.com,your-domain.vercel.app
CORS_ALLOWED_ORIGINS=https://your-domain.com,https://your-domain.vercel.app
CSRF_TRUSTED_ORIGINS=https://your-domain.com,https://your-domain.vercel.app
DATABASE_URL=postgresql://user:password@host:port/database
```

Generate a secure SECRET_KEY:
```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

### Step 3: Database Setup

For local development with production database:

```bash
export DATABASE_URL='postgresql://user:password@host:port/database'
python manage.py migrate
python manage.py createsuperuser
```

### Step 4: Deploy

```bash
git push origin main
# Vercel will automatically detect and deploy
```

## Verifying Static Files

After deployment:

1. Visit your app URL: https://your-app.vercel.app
2. Check that CSS loads - should see styled page
3. Open DevTools → Network tab
4. Verify `/static/styles.css` returns 200 status
5. Check for any 404 errors on static assets

## Troubleshooting

### Static files still not loading

1. **Clear Vercel cache**: Go to Settings → Deployments → Clear cache
2. **Check build output**: Look at deployment logs for `collectstatic` errors
3. **Verify paths**: Ensure STATIC_ROOT and STATIC_URL match vercel.json

### CSS not applied but loads

- May be CORS/CSP policy issue
- Check browser console for CSP violations
- Verify SECURE_CONTENT_SECURITY_POLICY in settings.py

### Images showing broken

- Image references should use proper paths
- Add fallback CSS styles (already included in styles.css)
- Consider using placeholder services for missing avatars

### Database connection errors

1. Verify DATABASE_URL format: `postgresql://user:pass@host:port/db`
2. Enable SSL: Add `?sslmode=require` to DATABASE_URL if needed
3. Check network access from Vercel to database

### 502 Bad Gateway

1. Check function logs in Vercel dashboard
2. Verify ALLOWED_HOSTS includes your deployment domain
3. Run migrations: Manually trigger migration if needed
4. Check SECRET_KEY is properly set

## Performance Optimization

### Static Files Caching

WhiteNoise with CompressedManifestStaticFilesStorage:
- Creates versioned filenames (e.g., `styles.abc123.css`)
- Sets long-term cache headers (1 year max-age)
- Compresses assets with gzip/brotli
- Already configured in vercel.json with 1-hour cache

### Media Files

For user-uploaded media:
1. Consider using external storage (AWS S3, Cloudinary)
2. Or enable persistent storage via Vercel's native options
3. Update MEDIA_URL and MEDIA_ROOT in settings.py
